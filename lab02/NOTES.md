рабочая папка - папка в которой ты находишься
индекс - черновик следующего коммита
коммит - сохраненный снимок индекса с автором, датой, сообщением, и ссылкой на предыдущий коммит.
git - локальная система контроля версий
github - удаленная система контроля версий(место где их удобно хранить)
git diff - сранивает рабочую папку с индексом
git diff --staged - сравнивает индекс с последним коммитом
git status - показывает, какие файлы изменены, какие уже в индексе, а какие гит вообще не отслеживает
git push -u origin main - отправляет все на гитхаб
